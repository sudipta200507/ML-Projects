# ML Projects

Reproducible classical machine-learning projects using public real-world datasets.

Projects:
- 01-bike-demand-regression — Linear Regression
- 02-bank-marketing-classification — Logistic Regression
- 03-income-classification — Random Forest
- 04-breast-cancer-diagnosis — SVM
- 05-phishing-website-classification — k-NN

Each project contains dataset retrieval, preprocessing, training, evaluation, model persistence and prediction.

Clone: `git clone https://github.com/sudipta200507/ML-Projects.git`

Then enter a project, create a virtual environment, install requirements, run `python download_data.py`, `python train.py`, and `python predict.py`.

Datasets are downloaded at runtime and are not committed to GitHub.
