# Dataset Registry

Every dataset used by this repository is public and has a documented upstream source. Download data locally; do not commit it.

| Project | Dataset | Official page | Direct download |
|---|---|---|---|
| 01 | UCI Bike Sharing (275) | https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset | https://archive.ics.uci.edu/static/public/275/bike+sharing+dataset.zip |
| 02 | UCI Bank Marketing (222) | https://archive.ics.uci.edu/dataset/222/bank+marketing | https://archive.ics.uci.edu/static/public/222/bank+marketing.zip |
| 03 | UCI Adult (2) | https://archive.ics.uci.edu/dataset/2/adult | https://archive.ics.uci.edu/static/public/2/adult.zip |
| 04 | UCI Breast Cancer Wisconsin Diagnostic (17) | https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic | https://archive.ics.uci.edu/static/public/17/breast+cancer+wisconsin+diagnostic.zip |
| 05 | UCI Phishing Websites (327) | https://archive.ics.uci.edu/dataset/327/phishing | https://archive.ics.uci.edu/static/public/327/phishing+websites.zip |

The project scripts use `ucimlrepo` for programmatic retrieval where practical, while the links above provide a human-verifiable source.
